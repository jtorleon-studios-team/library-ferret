## Intro :

Library Ferret is a library mod designed to centralize shared code for JTorLeon Studios' mods. While it doesn't add visible content on its own, it is crucial for the functionality of other mods from our studio.

Originally, this mod included items and blocks, but in the next version, only the "coins" item functionality will be retained. However, Library Ferret has the potential to serve as a foundation for other systems in the future, such as currency systems or custom game mechanics, offering a versatile toolkit for mod developers.

Even if you're not using other JTorLeon Studios mods, Library Ferret could still be useful for integrating custom features or expanding your own projects, like the coins.
